# Learning path content review

These lessons and practice questions were written for Lexiverse. They are not official WAEC, NECO or exam-board questions, and the app says so on every path.

Please ask an English teacher to check each lesson. Tick the box when a lesson is correct, or write the fix next to it. Source files are in `src/content/paths/`.
